# targeted-fixes

Taken by `macfixes`. Includes workarounds for Rosetta 2. They change default behaviour only where nobody would want the old behaviour.

The set's patches apply in order number, together with the other sets
a flavour takes. Layout and header format: [patches/README.md](../../README.md).
