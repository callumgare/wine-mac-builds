# essential-fixes

Taken by `macfixes`. Plain `wine` doesn't take it, so it stays WineHQ's release as released. A patch goes here when, without it, Wine won't start, shows nothing, hangs or crashes for a broad range of programs or Macs, and nobody would want the old behaviour.

The set's patches apply in order number, together with the other sets
a flavour takes. Layout and header format: [patches/README.md](../../README.md).
